## Brand & Style

This design system establishes an atmospheric, high-precision personal portfolio for a principal AI engineer and researcher. It embodies the nexus of computational intelligence, cutting-edge machine learning architecture, and bespoke digital craft. 

The aesthetic synthesizes modern **Glassmorphism** with an ambient **Cyber-Minimalism**:
- Deep, obsidian voids provide boundless negative space, directing sharp focus toward complex technical artifacts.
- Bioluminescent violet and electric cyan energy conduits symbolize neural activations, tensor flows, and algorithmic precision.
- Surfaces feel optical and tactile, utilizing frosted glass textures, microscopic hairline boundaries, and controlled ambient radiation.
- Tone: Visionary, deeply technical, authoritative, yet effortlessly refined. It rejects chaotic retro-cyberpunk tropes in favor of clean mathematical beauty, quiet confidence, and cinematic restraint.

## Colors

The palette relies on deep abyssal dark tones counterbalanced by hyper-saturated photonic accents.

### Palette Architecture
- **Canvas & Void**:
  - Base Background: `#090A0F` (True Obsidian)
  - Surface Midtone: `#0E1017` (Charcoal Carbon)
  - Elevated Container: `#131722` (Deep Nebula Slate)
- **Primary Energy (Neural Purple / Violet)**:
  - Base Core: `#8B5CF6`
  - Deep Spectral Focus: `#7C3AED`
  - High-intensity Glare: `#A78BFA`
- **Secondary & Accent (Cybernetic Cyan & High-Tech Blue)**:
  - Precision Cyan: `#06B6D4` (Logic pipelines, active metrics, runtime highlights)
  - Compute Blue: `#3B82F6` (Secondary pathways, structural links)
  - Luminous Highlight: `#67E8F9` (Micro-glows, focus ticks)
- **Neutrals & Monochromes**:
  - Text Primary: `#F8FAFC` (98% Crisp Signal)
  - Text Secondary: `#94A3B8` (Sub-spectral Metadata)
  - Text Muted: `#475569` (Inactive / Hash references)
  - Ghost Borders: `rgba(255, 255, 255, 0.08)` to `rgba(139, 92, 246, 0.25)`

## Typography

The typographical hierarchy strikes a deliberate balance between structural futurism, pristine legibility, and technical credibility:

- **Display & Headlines (Space Grotesk)**: Geometric, technical proportions with characterful mechanical hooks. Used strictly for section anchors, dynamic project titles, and monumental impact phrases. High negative letter-spacing creates optical tension and modernity.
- **Body & Editorial (Inter)**: Clean, neutral, high-legibility workhorse that absorbs complex mathematical text, case studies, and engineering achievements without visual friction.
- **Code & Diagnostics (JetBrains Mono)**: Reserved for model telemetry, pill badges, benchmark data, model weights (e.g., `FP16`, `70B`), and parameter counts. Renders the engineer's domain language with surgical accuracy.

## Layout & Spacing

The portfolio is orchestrated on a 12-column dynamic fluid grid bounded by a maximal container width of `1280px` for optimal viewing on ultra-wide developer displays.

- **Breakpoints**:
  - `Desktop`: `>= 1024px` (12 columns, `margin-desktop: 5rem`, `gutter: 2rem`)
  - `Tablet`: `768px – 1023px` (8 columns, `margin: 2rem`, `gutter: 1.5rem`)
  - `Mobile`: `< 768px` (4 columns, `margin-mobile: 1.25rem`, `gutter-sm: 1rem`)
- **Spacing Cadence**:
  - Layout structures maintain strict 8px/16px rhythms.
  - Generous vertical padding (`space-xl` scaled up to `5rem`–`8rem` between major portfolio chapters) provides the necessary negative space to let glass cards and radial glows breathe against the obsidian canvas.

## Elevation & Depth

Visual hierarchy does not rely on opaque drop shadows; instead, it is synthesized through semi-translucent substrate layering, backdrop filtration, and photon emissions:

- **Tier 0 (Substrate Void)**: `#090A0F` flat base canvas with subtle radial micro-mesh gradients (`rgba(139, 92, 246, 0.04)` and `rgba(6, 182, 212, 0.03)`).
- **Tier 1 (Glass Container Panels)**: Background `rgba(19, 23, 34, 0.55)`, `backdrop-filter: blur(16px) saturate(180%)`, encased in a hairline ghost border of `1px solid rgba(255, 255, 255, 0.08)`.
- **Tier 2 (Active Interactive Cards & Modals)**: Background `rgba(25, 30, 45, 0.70)`, `backdrop-filter: blur(24px)`, encased in `1px solid rgba(139, 92, 246, 0.25)`.
- **Radiance Tiers (Shadow / Glow Physics)**:
  - *Standard Card Ambient*: `0 8px 32px -4px rgba(0, 0, 0, 0.6)`.
  - *Violet Excitation (Primary interactive state)*: `0 0 24px -2px rgba(139, 92, 246, 0.35), 0 8px 32px 0 rgba(0, 0, 0, 0.8)`.
  - *Cyan Vector (Highlight state)*: `0 0 20px -2px rgba(6, 182, 212, 0.40)`.

## Shapes

The geometric architecture pairs soft technological corner radii with hyper-streamlined capsules:
- **Panels, Windows, and Artifact Cards**: Employ standard level-2 rounding (`0.5rem` to `1rem` via `rounded-lg`) to evoke polished physical hardware instrumentation and terminal chassis.
- **Micro-Artifacts & Pills**: Interactive tags, neural metrics, status lights, and master CTA buttons use complete continuous pill geometries (`rounded-full` / `9999px`) to emphasize fluidity, modularity, and atomic cohesion.

## Components

### Buttons & Call-to-Actions
- **Primary Cybernetic CTA**:
  - Pill-shaped (`rounded-full`), background gradient from `#8B5CF6` to `#7C3AED`.
  - Typography: `label-lg`, white text.
  - Box shadow: `0 0 20px rgba(139, 92, 246, 0.45)`.
  - Interaction: On hover, expands optical glow (`0 0 32px rgba(139, 92, 246, 0.70)`), with an internal hairline light shimmer traversing from left to right.
- **Secondary Glass Ghost**:
  - Background `rgba(255, 255, 255, 0.03)`, `backdrop-filter: blur(8px)`.
  - Border: `1px solid rgba(255, 255, 255, 0.12)`.
  - Hover: Border switches to `rgba(6, 182, 212, 0.5)` with cyan text glow.

### Pill Badges & Diagnostic Chips
- Built for model versions, stack components (e.g., `PyTorch`, `CUDA`, `Transformer`), and deployment states.
- Fully rounded capsule shape. Background: `rgba(14, 16, 23, 0.8)`.
- Border: `1px solid rgba(6, 182, 212, 0.2)`.
- Content: Prefix with a pulsing 6px circular neon cyan LED (`box-shadow: 0 0 8px #06B6D4`). Font: `label-sm`.

### Glassmorphic Project & Research Cards
- Surface: Multi-layered frosted slate (`rgba(19, 23, 34, 0.6)`), border radius `1rem`.
- Boundary: Subtle `1px` gradient border shifting diagonally from `rgba(255, 255, 255, 0.15)` down to `rgba(139, 92, 246, 0.05)`.
- Hover behavior: Subtle vertical transformation (`translateY(-4px)`), backdrop opacity elevates to `0.8`, and border illuminates with a radiant purple glow.

### Input Fields & Terminal Console
- Background: `#090A0F` inset, border: `1px solid rgba(255, 255, 255, 0.1)`.
- Font: `label-md` (JetBrains Mono).
- Active/Focus: Glow boundary transforms into `1px solid #8B5CF6` paired with `0 0 12px rgba(139, 92, 246, 0.25)`. Outline zeroed.

### Benchmark Data Grids & Metrics
- Monospaced numerical values set in `display-xl-mobile` with cyan-to-violet linear gradients.
- Sub-labels set in `label-sm` in all caps with `0.08em` tracking in `#94A3B8`.
